# SolanaPay-KZ brand

The mark is the tenge sign ₸ drawn with slanted bars, a nod to Solana's mark. The gold top bar is the sun of the
Kazakh flag.

| File | Use |
|---|---|
| `logo-mark.svg` | The mark alone: app icon, favicon, avatars. |
| `logo-lockup.svg` | Mark and name on light backgrounds. The name is outlined, no font needed. |
| `logo-lockup-dark.svg` | Mark and name on dark backgrounds. |

The payment pages serve the mark as `/assets/logo.svg`, the wallet and Blink icon as `/assets/icon.png` (512 px), and
`/assets/favicon-32.png` and `/assets/apple-touch-icon.png` (180 px), all from `tilda-server/public/`.

## Colours ("Steppe Sky")

| Name | Hex | Use |
|---|---|---|
| Sky | `#00799A` | Mark background, buttons, links |
| Sun | `#F2C200` | Top bar of the mark only |
| Ink | `#0B2233` | Text, name on light backgrounds |
| Mist | `#EEF5F9` | Page background |
| Paper | `#FFFFFF` | Cards, bars of the mark |

## Type

Unbounded Bold for the name, headings and KZT amounts; Golos Text for the interface; JetBrains Mono for addresses and
token amounts. All three are under the SIL Open Font License (copies in `tilda-server/public/fonts`).

## Do not

- Recolour the bars or put the mark on a background close to Sky without the rounded square.
- Use the Solana Foundation's gradient or logo in the mark; SolanaPay-KZ is an independent project built on Solana Pay.
