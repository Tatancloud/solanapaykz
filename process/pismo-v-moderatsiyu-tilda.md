**Тема:** Универсальная платежная система: шаблон «Оплата криптовалютой (USDC на Solana)», проект 10868059

Здравствуйте.

Мы подключили универсальную платежную систему в проекте 10868059 по варианту
«Новая платежная система (для разработчиков)» и просим проверить шаблон.

**Что это за платежная система.** Приём оплаты в криптовалюте (USDC и SOL в сети
Solana) с ценой в тенге. Решение с открытым исходным кодом, предназначено для
казахстанских магазинов: https://github.com/Tatancloud/solanapaykz
Документация: https://tatancloud.github.io/solanapaykz/

**Настройки в кабинете:**

- ID платежной системы: 3061174
- Логин: solanapaykz
- Валюта: KZT, страна KZ
- API URL и тестовый API URL: https://pay.kabyldau.digital/tilda/pay
- URL для уведомлений (выдан Tilda): https://forms.tildaapi.pro/payment/custom/ps3061174
- Подпись заказа и подпись уведомления: HMAC-SHA-256, секрет как ключ алгоритма
- Демо-страница с корзиной: https://kzwedding.tilda.ws/solanapay

**Вопрос, с которым мы застряли.** Провести тестовый платеж не удаётся:
корзина не доходит до шага оплаты.

При оформлении заказа корзина отправляет в `https://forms.tildaapi.pro/procces/`
корректные данные платежа:

```
tildapayment = {"currency":"KZT","amount":90,"system":"custom","products":[...]}
```

В ответ приходит:

```json
{"message":"OK","results":["10868059:8669924544"]}
```

В ответе нет объекта `next`, поэтому `tilda-forms-1.0.min.js` не вызывает
`window.tildaForm.payment()` и покупатель остаётся на странице с сообщением об
отправленных данных. Запрос до нашего API URL не доходит вовсе — по журналам
нашего сервера обращений нет.

В настройках платежной системы: «Отключить платежную систему» не отмечено,
в разделе «Платежные системы» проекта она показана как «Активировано».
В записи системы поле `template` пустое, `statusid` = 1.
